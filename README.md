# Flag Project 2

**Flag Project 2** is a front-end web application that displays a selection of country flags and related information.  
This project demonstrates use of **HTML**, **CSS**, and **JavaScript** to create a clean, responsive interface and dynamic content.

---

## 🌐 Live Demo

Try it here:  
👉 https://bahadirbektore.github.io/flag-project-2/

---

## 🚀 Project Overview

This project includes:

- A gallery of country flags  
- Clean and responsive layout  
- Interactive elements for displaying flag information  
- Use of semantic HTML structure

---

## 🛠 Technologies Used

This project was built using:

- **HTML5** – Semantic markup  
- **CSS3** – Responsive styling and layout  
- **JavaScript** – Dynamic interaction

1. Open the live demo link above.
